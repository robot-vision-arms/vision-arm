## 3. 겪은 문제와 해결

| 문제 | 해결 |
|---|---|
| WSL 메모리가 7.6 GB 로 돌아감 (`.wslconfig` 가 사라짐) | 다시 작성해 10 GB / swap 8 GB |
| conda 의 python 이 먼저 잡힘 | 자동 활성화 끄기, `env.sh` 로 순서 고정 |
| 패드를 붙인 URDF 와 SRDF 의 로봇 이름이 다름 | 둘 다 `ur5e` 로 통일 |
| 패드가 손목과 충돌로 판정됨 | 고정 장착 부위끼리의 충돌만 제외 (다른 충돌 검사는 유지) |
| 기본 계획 시간 0.5초로 이동 실패 | 5초로 늘림 |
| 나무 무늬·그림자를 부품으로 잡음 | 밝기 대신 채도·명도를 함께 보는 `metal_hsv` |
